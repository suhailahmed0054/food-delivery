# CLAUDE.md

## Project
This is a food ordering / delivery web app for Al-Arab Restaurant.

## Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB / local JSON during development
- Payments: Razorpay
- Maps: OpenStreetMap / Nominatim / Browser Location API

## Main Modules
- Customer app
- Admin dashboard
- Staff / delivery module

## Important Rules
- Do not delete existing features unless asked.
- Keep the UI simple, clean, and mobile-friendly.
- Explain changes in simple words.
- Use TypeScript properly.
- Fix errors step by step.
- Before big changes, explain what files will be changed.
- Keep frontend and backend code organized.
- Do not hardcode secret keys or API keys.
- Use environment variables for secrets.

## Features in Project
- Customer login/register
- Menu browsing
- Cart and checkout
- Online payment
- COD orders
- Admin live orders
- Staff/delivery assignment
- WhatsApp delivery message support
- Support ticket / issue system
- QR table ordering

## How to Help
When I ask for a feature:
1. Understand the current code first.
2. Tell me the plan shortly.
3. Then give the code changes.
4. Mention which files to edit.
5. Help me test it after changes.
